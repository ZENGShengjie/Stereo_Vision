# 性能面板（/perf）使用指南

> 访问 `https://localhost:9000/perf` 打开性能面板。包含实时运行状态和可调算法参数。

---

## 第一排：实时运行状态（只读，自动更新）

| 参数 | 含义 | 怎么看 |
|------|------|--------|
| **FPS** 8.3 | 系统处理帧率 | 数字越高越好。一般 10+ 是流畅的，5 以下会卡顿。 |
| **DEPTH** 20.1 cm | 相机到目标的距离 | 这是基于 SGBM 视差算出来的物理距离。如果 YOLO 没检测到目标，会显示异常值。 |
| **DISP** 496.0 | 当前帧的视差值（像素） | 视差越大 = 目标越近。视差越小 = 目标越远。这个值最直观地反映"远近"。 |
| **CONF** 10% LOW | 视差可信度百分比 | 显示 LOW/OK/HIGH。如果显示 LOW，说明 SGBM 匹配不可信，深度可能不准。 |
| **STATUS** unreachable | 当前检测状态 | reachable = 找到目标且距离合理；unreachable = 没找到或距离异常。 |
| **PATH** / ROI / no_box | 当前处理路径 | roi = 用了 ROI 加速；full = 整图 SGBM；no_box = 没 YOLO 检测框。 |

---

## 第二排：核心算法参数（可调，影响效果）

| 参数 | 默认值 | 作用 | 怎么调 |
|------|--------|------|--------|
| **DISP_SCALE** | 1.1111 | SGBM 输出视差的缩放系数 | 这是 HFOV 标定用的修正系数。一般不用动。如果深度值和实际距离系统性的偏差（比如总是偏小 10%），可以微调这个值。 |
| **BASELINE (cm)** | 6 | 双目相机基线距离（两镜头物理间距） | 这个值是物理测量出来的，改它会直接影响深度计算。改它只用于实际基线和默认值不符的情况。 |
| **HFOV (deg)** | 80 | 相机水平视场角 | 当没有标定文件时，用这个估算焦距（`fx = MONO_W / (2 * tan(HFOV/2))`）。如果标定文件有效，这个值不影响深度计算。 |
| **NUM DISP** | 192 | SGBM 视差搜索范围（像素） | 调大：能测更远的目标，但计算变慢。调小：只测近处目标，速度更快。一般设为 64 的倍数。 |
| **BLOCK** | 5 | SGBM 匹配块大小（奇数） | 调大（如 7、9）：匹配更稳定，但细节变模糊，近处物体易丢失。调小（如 3）：细节更多，但噪声大、易误匹配。 |
| **焦距校准 (cm)** | 25 | 重新校准用的参考距离 | 把目标放在距离相机 25cm 处，点击这个按钮，会自动校准 DISP_SCALE。 |
| **恢复默认** | — | 一键还原所有默认值 | 误改参数后用这个恢复。 |

---

## 实用调参指南

### 场景 1：深度值明显不准

把目标放在已知距离（比如 25cm），点击"焦距校准 25 cm"，系统会自动调整 DISP_SCALE 让深度显示为 25cm。

### 场景 2：FPS 太低，画面卡

- 减小 NUM DISP（比如 192 → 128）
- 减小 BLOCK（比如 5 → 3）

### 场景 3：远处目标检测不到

- 增大 NUM DISP（比如 192 → 256）

### 场景 4：杯子的视差值跳动大

- 增大 BLOCK（比如 5 → 7）
- 查看 CONF 状态，如果一直 LOW，说明环境光照/纹理有问题

---

## 关键关系

```
深度 Z = (fx × 基线) / (视差 × DISP_SCALE)
```

- **fx** = 焦距（标定或 HFOV 估算）
- **基线** = 两相机物理距离
- **视差** = DISP 实时显示的值
- **DISP_SCALE** = 修正系数（默认 1.1111）

所以调整这三个乘子中的任何一个，都会直接改变最终深度 Z 的值。
